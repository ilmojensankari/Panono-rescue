# Release notes

## 1.0.0 — 10 September 2026

- First public release of Panono Rescue by ilmojensankari.
- Universal Mac application for Apple Silicon and Intel, with a new app icon.
- Camera library, UPF downloads, spherical previews, HDR and native shutter timers.
- Manual/automatic exposure controls and camera-supported white balance.
- System-time synchronization and optional capture location metadata.
- Optional donations through Monero, Bitcoin and Ko-fi.

The app and DMG are signed with Developer ID and notarized by Apple. The ZIP
contains the same notarized app. Checksums are included with the downloads.

The macOS 14 deployment target is checked by the compiler. Runtime verification
has been performed on macOS 26.6.2 on Apple Silicon, with Intel code tested using
Rosetta. Native execution on an Intel Mac and runtime testing on macOS 14 are
not yet available.
